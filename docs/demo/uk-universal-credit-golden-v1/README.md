# Universal Credit golden dataset v1 - specialist review pack

This directory contains a synthetic Universal Credit evidence ZIP generated by the production pack generator through an isolated end-to-end test.

## Files

- `universal-credit-golden-v1.zip` - the evidence pack for specialist review;
- `artifact.sha256.json` - the fixture hash, immutable review snapshot hash, ZIP hash and byte size;
- `../../review/uk-universal-credit-golden-dataset-v1/specialist-review-checklist-en.md` - English review checklist;
- `../../review/uk-universal-credit-golden-dataset-v1/specialist-review-checklist-pl.md` - Polish review checklist.

## Scenario

- synthetic sole trader in Northern Ireland;
- not registered for VAT;
- assessment period from 23 November 2026 to 22 December 2026;
- expected income: GBP 1,290.00;
- expected expenses: GBP 199.00;
- expected net income: GBP 1,091.00;
- expected preflight: amber because synthetic source documents are intentionally absent.

The companion integrity metadata classifies the artifact as `DEMO / NOT FOR SUBMISSION`. Inside the ZIP, the manifest identifies it as Universal Credit evidence and explicitly states that it is not submission confirmation. It is not a Universal Credit submission receipt, professional approval or tax advice.

## Integrity check

Compare the SHA-256 and size of the ZIP with `artifact.sha256.json`. The fixture used by the test is hash-locked in `resources/demo/uk-universal-credit-golden-dataset/v1.json`.

PowerShell example:

```powershell
Get-FileHash docs/demo/uk-universal-credit-golden-v1/universal-credit-golden-v1.zip -Algorithm SHA256
```

## Controlled regeneration

Run the isolated test with an explicit export flag:

```powershell
$env:GENERATE_UC_GOLDEN_PACK = '1'
php artisan test tests/Feature/Finance/UniversalCreditGoldenDatasetTest.php
Remove-Item Env:GENERATE_UC_GOLDEN_PACK
```

Without that flag, the test uses fake private storage and does not change files in this directory.
